# Abdul Azeez — Software Developer Portfolio (V2)

A responsive, data-driven developer portfolio built with semantic HTML, modern CSS, and vanilla JavaScript featuring dynamic color-shifting animations, Dark/Light mode, local certificate images, and achievement timelines.

## Quick Customization (`js/data.js`)
Open `js/data.js` and update:
1. `PORTFOLIO_DATA.projects` → `quickcheckout` → `liveUrl`: paste your deployed QuickCheckout System URL.
2. `PORTFOLIO_DATA.profile.email`: your email address for the contact card and email-draft form; optionally set `resumeUrl`.

## Deploy to Vercel
1. Unzip this folder and push to GitHub (or run `npx vercel`).
2. Framework Preset: **Other** (static HTML/CSS/JS — zero build step required).
